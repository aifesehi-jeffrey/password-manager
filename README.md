# password-manager
## Project Overview
A CLI password manager that stores encrypted credentials
## Features
Search record: Allows the user to search for a record containing all their information like the record id, website, username/email, and password.
Create record: Allows the user to create one of these records by giving the website, their username/email, and their password.
List all records: Allows the user to view every record in the database by listing all the records out.
Delete record: Allows the user to delete a record by typing their id and typing their password as confirmation for the deletion.
